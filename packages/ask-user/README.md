# @pureooze/pi-ask-user

Adds an `ask_user` tool that lets Pi ask a question with selectable options and optional free-form answers.

## Install

```bash
pi install npm:@pureooze/pi-ask-user
```

The extension uses Pi's UI only. It does not make network requests or read/write files itself. Answers become part of the current Pi interaction and may therefore be retained in the normal Pi session history.
